# Dicionário de Linguagem Ubíqua

Este dicionário reúne os termos usados no domínio da Autoshop clientes, administradores, mecânicos e equipe de
desenvolvimento compartilhem o mesmo entendimento.

| Termo                     | Definição                                                                                                                                                                                                                              |
|---------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **OS**                    | Abreviação de **Ordem de Serviço**.                                                                                                                                                                                                    |
| **Cliente**               | Pessoa que solicita uma Ordem de Serviço para um veículo.                                                                                                                                                                              |
| **Mecânico**              | Prestador de serviço que realiza consertos nos veículos.                                                                                                                                                                               |
| **Administrador**         | Prestador de serviço responsável por atender os clientes, iniciar Ordens de Serviço e gerir peças e insumos.                                                                                                                           |
| **Ordem de Serviço (OS)** | Documento que registra o que deverá ser feito para consertar o veículo. No sistema, está associada a um cliente e a um veículo, reúne os serviços previstos e mantém o status, a estimativa total e as datas de criação e atualização. |
| **Orçamento**             | Documento com informações, valores e observações sobre o serviço prestado.                                                                                                                                                             |
